SET AS HOMEPAGE

如何将薄荷起始页设为主页

浏览器出于安全考虑，不允许网页直接修改主页。找到你正在使用的浏览器，照着下面的步骤操作即可。

薄荷起始页网址

电脑浏览器

展开对应浏览器查看设置方法

CChrome 浏览器当前浏览器

设置入口 chrome://settings/onStartup

  1. 复制上面的设置入口，粘贴到 Chrome 地址栏并按回车。
  2. 在“启动时”中选择 打开特定网页或一组网页，点击“添加新网页”。
  3. 粘贴 https://mintstart.cn/，点击“添加”。
EEdge 浏览器当前浏览器

设置入口 edge://settings/onStartup

  1. 复制上面的设置入口，粘贴到 Edge 地址栏并按回车。
  2. 选择 打开以下页面，再点击“添加新页面”。
  3. 粘贴 https://mintstart.cn/，点击“添加”。
FFirefox 浏览器当前浏览器

设置入口 about:preferences#home

  1. 复制上面的设置入口，粘贴到 Firefox 地址栏并按回车。
  2. 在“主页和新窗口”右侧选择 自定义网址。
  3. 在网址栏粘贴 https://mintstart.cn/。
SSafari 浏览器当前浏览器
  1. 在 Mac 屏幕左上角选择 Safari 浏览器 → 设置。
  2. 打开 通用，在“主页”一栏粘贴 https://mintstart.cn/。
  3. 如需启动时显示主页，将“新窗口打开方式”也设为 主页。
360360 安全浏览器当前浏览器

设置入口 se://settings/browser

  1. 复制上面的设置入口，粘贴到浏览器地址栏并按回车。
  2. 找到“启动时打开”，点击 修改主页。
  3. 输入 https://mintstart.cn/ 并确认。
360360 极速浏览器当前浏览器

设置入口 chrome://settings/browser

  1. 复制上面的设置入口，粘贴到浏览器地址栏并按回车。
  2. 在“启动时”中选择 打开主页。
  3. 在后方输入 https://mintstart.cn/。
S搜狗浏览器当前浏览器

设置入口 se://settings/?category=general

  1. 复制上面的设置入口，粘贴到浏览器地址栏并按回车。
  2. 在“主页”一栏选择 自定义，点击“设置网址”。
  3. 输入 https://mintstart.cn/ 并确认。
QQQQ 浏览器当前浏览器

设置入口 qqbrowser://settings/

  1. 复制上面的设置入口，粘贴到浏览器地址栏并按回车。
  2. 在“启动时打开”中选择 主页，点击右侧“设置”。
  3. 选择“自定义网站”，输入 https://mintstart.cn/ 并确认。

手机浏览器

手机端可添加到主屏幕，像 App 一样打开

MiPhone / Android当前设备
  1. iPhone Safari：点击底部“分享”按钮，再选择“添加到主屏幕”。
  2. Android Chrome：点击右上角菜单，再选择“添加到主屏幕”或“安装应用”。
  3. 添加完成后，直接点击桌面上的 薄荷起始页 图标即可。

提示：不同浏览器版本的文字可能略有差异。如果找不到对应选项，可在浏览器设置中搜索“启动时”“主页”或“首页”。
