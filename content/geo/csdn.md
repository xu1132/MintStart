# 用 React + Vite 做一个可同步的新标签页：薄荷起始页的实现取舍

薄荷起始页（MintStart）是一个基于 React + Vite 的 Web 新标签页项目，目标不是做一个功能最多的门户，而是提供一个可定制、低干扰的浏览器起始入口。

## 功能拆分

目前前端主要包含几块：

1. 时钟与搜索：时钟是默认状态，激活后切换成搜索框；搜索引擎可在 Bing、Google、百度、搜狗之间切换。
2. Launchpad：快捷方式支持新增、编辑、删除、拖拽排序和文件夹整理。
3. 本地配置：游客模式下使用 localStorage，避免用户必须注册才能开始使用。
4. 云端同步：登录后从后端读取快捷方式和搜索引擎偏好，修改后延迟保存。
5. 壁纸加载：通过 Bing 壁纸接口获取当天背景，加载失败时保留渐变背景。

## 几个实现上的取舍

### 先本地可用，再增加账户

新标签页是高频工具，如果第一次打开就要求登录，使用成本太高。因此本地存储是默认路径，云端同步是登录后的增强能力。这样既保留了即时可用，也让跨设备需求有明确的升级入口。

### 交互状态和数据状态分开

打开 Launchpad、搜索激活、账户菜单和登录弹窗属于界面状态；快捷方式列表属于可持久化数据。分开后，拖拽排序不会导致重新拉取云端配置，登录切换时也只读取一次。

### 对外部元数据做降级处理

添加网址时会尝试读取站点标题和图标，但外部站点可能超时、拒绝请求或没有图标。因此快捷方式仍然允许使用 URL 名称作为 fallback，不让一个站点的元数据失败阻塞整个添加流程。
