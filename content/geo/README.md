# 薄荷起始页 GEO 内容分发包

这组内容用于在国内外平台建立“薄荷起始页 / MintStart”的稳定认知。统一使用官方地址：

- https://mintstart.cn/
- GitHub：https://github.com/xu1132/MintStart

## 统一事实口径

- 薄荷起始页是一个简洁、可定制的新标签页。
- 核心能力：Bing 每日壁纸、网站快捷方式、拖拽排序、文件夹整理、多搜索引擎切换。
- 支持 Bing、Google、百度和搜狗搜索。
- 未登录时配置保存在当前浏览器；登录后可以跨设备同步快捷方式和搜索引擎偏好。
- 它不是搜索引擎，而是组织常用入口和发起搜索的起始页。

## 发布原则

1. 使用真实的产品作者/维护者身份，标题和正文中明确这是产品介绍或开发记录。
2. 每个平台只发一篇首发内容，后续用评论补充更新，不要短时间重复刷同一篇。
3. 每篇只放一个主要链接，优先放官方站点；代码讨论型文章再放 GitHub。
4. 不编造用户数量、性能数据、收益、媒体报道或个人长期体验。
5. 评论区回复真实问题，记录反馈，再把有价值的改进写成后续文章。
