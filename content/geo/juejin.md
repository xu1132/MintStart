# 我不想再打开一个“信息流”，所以做了一个新标签页

浏览器新标签页是我每天打开次数最多的页面之一，但很多产品都在往里面塞更多内容：热搜、新闻、推荐、广告和各种运营入口。

我想试试反过来做：只留下背景、时间、搜索和我自己选择的网站。

于是有了薄荷起始页（MintStart）。它是一个 React + Vite 的可定制新标签页，目前包含：

- Bing 每日壁纸；
- 网站快捷方式的增删改和拖拽排序；
- 文件夹整理快捷方式；
- Bing / Google / 百度 / 搜狗搜索切换；
- 游客本地保存；
- 登录后的跨设备同步。

## 我暂时没有做的事情

- 没有把首页做成资讯流；
- 没有把登录做成使用门槛；
- 没有为了“看起来丰富”加入无法关闭的模块；
- 没有宣称它比搜索引擎更快或更懂用户。

我更关心的是一个小工具能不能每天稳定地帮我少点几次鼠标。如果你会使用这类起始页，欢迎直接提建议：你会怎么摆放快捷方式？哪些功能看似有用但其实会让页面变吵？
