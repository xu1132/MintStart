## Launchpad 分页（三行/页 + 指示器 + macOS 式滑动）
- 容量 PAGE_ROWS=3：桌面 6×3=18/页，≤600px 移动 4×3=12/页（pageCapacity 监听 resize）。结构：`.launcher-stage`(overflow hidden, flex column) > `.launcher-pages`(flex 轨道, translateX(-page*100%)) > 多个 `.app-grid.app-page`(flex 0 0 100%)；"添加"tile 恒在末页末尾。
- 指示器：dots 在 stage 内网格下方（贴近 app），滑块式 `.dot-pill`（20px 白色 pill，translateX(calc(var(--page)*17px - 6.5px))），与轨道同 easing cubic-bezier(.22,1,.36,1) .48s，视觉同步。
- 翻页途径：触控板横向 wheel（跟手 1:1 位移 + 140ms 停顿吸附/惯性 flick lastDelta>60）、触摸/鼠标拖拽（阈值 max(56, 18%宽) 或速度>0.45px/ms 甩动）、方向键、圆点点击、拖拽到左右 72px 边缘自动翻页。边缘橡皮筋 ×0.3。
- 关键坑：resetPan 必须把内联 transform/transition 恢复为 React 应渲染的值（不能清空），否则手势结束页码未变时 DOM 与 React 样式脱节点。
- 触摸从图标起手势：快速(<150ms)横滑=翻页，长按 180ms 后=dnd 拖拽（互斥已处理：onDragStart resetPan、fromTile tap 不关闭 launcher）。
- dnd droppable 测量改 WhileDragging（翻页后 rect 变化）；跨页合并安全：指针悬空白即清 fallbackOver，finishDrag 不会误并旧页图标。
- FLIP 补间仅同页内移动才做（page-local 坐标比较）。
- agent-browser 实测：30 apps → 2 页(18/13)、pill 随页滑动、滚轮/触摸/键盘/圆点/橡皮筋均正常。测试 11 全过。
- 方向修正：触控板滚轮手势原来按 deltaX 正向映射，与 macOS 自然滚动相反（手指左滑 deltaX>0 应=内容向左=下一页）。已改为 offset=-acc、acc>0→下一页。鼠标/触摸拖拽本就跟随手指（同向），未变。

## Launchpad 翻页重构为档位式橡皮筋（macOS 启动台手感）
- 核心思路：两页之间存在"走不通"的留白段——纯跟手位移封顶在页宽的 12%（常量 FULL=24%、RESIST=9% of width），永远到不了整页，松手只能弹回或已翻页，结构上不存在"卡住"。
- 映射 rubberBandToward：|raw|≤24%宽 1:1 跟手，超出部分 ×0.24 衰减并封顶 33%宽；首末页外侧 rubberBandOverscroll（10px 后 ×0.22、封顶 76px）。
- 判定 resolvePageStep：|raw + velocity×80| 过零界 max(60, 24%宽) 或 |v|>0.32px/ms 甩动 → 翻页，否则弹回原页；settlePage 动画 170–310ms 按距离/速度自适应。
- touch/mouse 与触控板 wheel 共用 panOffsetFor + resolvePageStep；beginPan/wheel 起手势时 freezeTrack 恢复（支持动画中再按下继续丝滑）；mode='ignore'/轻点关闭路径只清 panRef 不再 resetPan。
- freezeIndicator、constrainPageOffset 已删。构建通过、测试 11 全过。
